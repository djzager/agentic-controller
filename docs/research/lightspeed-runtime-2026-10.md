# Konveyor/Lightspeed reference findings — 20 October 2026

This is a narrow source reference for [the convergence investigation](https://redhat.atlassian.net/browse/MTA-7977), preserved for a future implementer. It contains prototype code and a concise findings summary. The larger historical reports, operational records, private fixture state, and generated output are not published here. No production integration or upstream agreement is claimed.

Konveyor will review and merge its direction ADR and OpenShell factual corrections in agentic-controller first, then approach Lightspeed separately with concrete follow-up tickets. This branch is evidence, not an enhancement proposal or a branch intended for merge.

## Findings and limits

**Operator execution:** operator `e195a026588c6db674e573a6bd4cff2b47e0e55d` ran a Konveyor-owned Go harness/Goose image with Secret-backed inputs, real Hub application resolution, Git clone/commit/push, and retained Result publication. Independent checks verified the output and unchanged source branch. This used a global image override, not per-invocation image selection. A higher-level Konveyor execution backend is unimplemented. Five synthetic cluster cases covered success, failure, limits, missing output, and cooperative timeout. A namespace probe exposed an invalid cross-namespace approval owner reference; shared execution placement was the measured path.

The [operator contract reference](https://github.com/djzager/lightspeed-agentic-operator/tree/792f28cb2a36055c7d6e88a8b7ea2c07ae7c402e/research/konveyor-contract) preserves the actual in-package envtest probe and reproduction instructions. All 13 subtests passed originally and again on 20 October. It adds no production behavior or image selector. Simulated completion/Pod state and a deliberately injected missing-Result read do not establish live lifecycle reliability.

**Runtime reuse:** an experimental harness based on Konveyor `41afab2c868d37a48b19e62641234e4c55b86d51` reused sandbox runtime `325121ba39db810b1e98f38e5a1ca8dc02fecdef` under direct Agent Sandbox. A packaged filesystem skill, external HTTP MCP nonce tool, model execution, and independently verified Git output passed. A required unreachable MCP server failed before inference. Go owned Hub/Git preparation, final push and normal token revocation. Keeping credentials out of the child environment is not isolation from hostile code in the same container; upstream shell subprocesses can inherit model credentials.

**Retained sessions and handoff:** the unchanged provider lost prior conversation context in three samples. A shared in-memory checkpointer with stable thread identity recalled a synthetic value in three samples; fresh-thread controls lacked it. Earlier strict assertions that failed on literal `[]` output artifacts were retained in the local record. Three fresh-process/HOME/clone stage pairs passed with committed handoff files over a local bare Git remote. A Python parent sequenced them; real Go/Hub workflow sequencing and shared-token ownership were not tested. Handoff is distinct from retaining a conversation.

**ACP:** first-party ACP multi-prompt/history behavior was tested separately with synthetic state. The live passive adapter used DeepAgents ACP 0.0.13 / ACP SDK 0.12.1 with DeepAgents 0.7.22, LangGraph 1.2.14 and checkpoint 4.2.0. Three live attempts retained an observer-startup failure, an inspection-blocked workload, and one combined pass. Both readiness-corrected observers loaded the same live session, replayed an exact completed-tool ID before load returned and observed new activity. The combined pass also verified skill/MCP markers, a new pushed commit, unchanged source branch, normal Hub-token revocation and run-resource cleanup. This is one success among three attempts, not a reliability or performance qualification.

The live adapter accepts one owner prompt; it does not demonstrate integrated multi-prompt runtime continuation. It extracts the graph-construction prefix from SHA-256-guarded internal upstream source, a feasibility technique rather than a supported interface. Model-boundary inspection remained enabled, but native ACP display bypassed the provider's delayed approved-result release. The fixture was benign. A blocked synthetic node still acted after cancellation in three samples; typed ACP prompt errors and usage coverage also remain incomplete. None of this establishes production inspection/display parity or safe cancellation.

**OpenShell:** source inspection pinned to v0.1.3 `e1f3c82caa3ed3b65de22889ae7ef32a774878ef` found that managed inference routing was removed while the gateway and provider credential isolation remained. An attachment authorizes native service access; it does not select a model or determine the lifetime of Konveyor's Gateway resource. No Konveyor/OpenShell deployment or compatibility was tested. The ADR PR carries factual corrections; actual integration remains separate.

## Agreed direction and successor work

Target Lightspeed's DeepAgents runtime within the Konveyor harness, retaining required Hub/Git behavior. Runtime reuse can ship under our existing controller/direct Agent Sandbox independently of operator adoption. Upstream per-invocation image selection and image-owned startup are prerequisites for adopting their operator. Do not ship a patched operator; defer that adoption if the capability misses 8.4. Preserve reusable capabilities/workflows and core workload outcomes across execution paths, with backend-specific publication added when required. Keep completed work visible if mandatory backend publication fails, and report the integration failure.

A supported reusable runtime interface is the first implementation boundary to agree. Retained conversation sessions are an important independent improvement: separate prompt completion from workload finalization, with transport still open. ask_user, steering, safe cancellation and durable recovery are separate work. Portability to direct Agent Sandbox, Lightspeed and OpenShell is a goal, not three qualified backends or a requirement to qualify all three for 8.4. Long-term ownership transfer is still to be negotiated.

See [the source and reproduction guide](../../hack/lightspeed-runtime-poc/README.md). No model or cluster run was repeated merely to publish this reference.
